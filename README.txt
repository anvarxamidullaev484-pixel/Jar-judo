JAR JUDO — veb-sayt

Ishga tushirish:
1. ZIP faylni oching.
2. jar_judo papkasini VS Code orqali oching.
3. index.html faylini brauzerda oching yoki VS Code Live Server orqali ishga tushiring.

Imkoniyatlar:
- Sportchi qo‘shish: ism, yosh, vazn toifasi.
- Sportchini o‘chirish (tasdiqlash bilan).
- Ism bo‘yicha qidirish.
- Ro‘yxat brauzerning localStorage xotirasida saqlanadi.
- Judo mavzusidagi dizayn va motivatsion gaplar.

Eslatma: ma’lumotlar hozircha faqat shu brauzer/qurilmada saqlanadi. Boshqa kompyuterlarda umumiy ro‘yxat bo‘lishi uchun server va ma’lumotlar bazasi kerak.
